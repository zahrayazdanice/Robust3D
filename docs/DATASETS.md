# Datasets and geometry sources

Robust3D does not commit third-party geometry. Open3D downloads supported sample meshes into its user cache on first use.

| Key | Display name | Source | Why it is useful |
|---|---|---|---|
| `bunny` | Stanford Bunny | Stanford 3D Scanning Repository via Open3D | recognizable organic surface and fine ears/feet |
| `armadillo` | Stanford Armadillo | Stanford 3D Scanning Repository via Open3D | articulated limbs and concavities |
| `knot` | Trefoil Knot | Open3D sample data | curved tube and nontrivial topology |
| `torus` | Analytic Torus | generated by Open3D | exact high-genus stress test |
| `sphere` | UV Sphere | generated by Open3D | smooth closed sanity check |

Source links:

- Stanford 3D Scanning Repository: <https://graphics.stanford.edu/data/3Dscanrep/>
- Open3D datasets API: <https://www.open3d.org/docs/release/python_api/open3d.data.html>
- ModelNet: <https://modelnet.cs.princeton.edu/>

ModelNet is not downloaded automatically because the full archive is large and its per-object meshes need category selection. To use it, convert/select an OFF mesh and pass it through the CLI or dashboard upload. OFF is supported by the reader.

## Adding a local object

```bash
robust3d reconstruct --input path/to/model.off --algorithm alpha --output result.ply
```

If the upload contains faces, Robust3D normalizes it and uses it as evaluation reference. If it contains only points, reconstruction remains available but reference-based accuracy metrics are not reported.

Always follow the original dataset license and citation requirements when publishing derived results.
